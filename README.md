## Descripción del proyecto

Studify es una aplicación web diseñada para estudiantes y profesores de la UPF que facilita la planificación académica, la gestión de asignaturas, el seguimiento del progreso y la comunicación entre usuarios.

El proyecto ha sido desarrollado siguiendo metodologías Agile (Scrum/Kanban) y utilizando GitHub para la gestión del trabajo colaborativo.
